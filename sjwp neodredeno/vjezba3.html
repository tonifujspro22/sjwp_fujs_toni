Web programiranje

Web programiranje obuhvaća razvoj i održavanje internetskih stranica i web aplikacija.

HTML

HTML je standardni označni jezik koji se koristi za izradu strukture web sjedišta.

Osnovni elementi

Osnovni elementi HTML-a sastoje se od oznaka koje definiraju različite vrste sadržaja na stranici.

Tekst

Tekstualni sadržaj je temelj svake web stranice i može se oblikovati na različite načine.

Odlomci

Odlomci se definiraju pomoću oznake p i služe za organizaciju teksta u čitljive cjeline.

Prijelomi redaka

Prijelomi redaka unutar teksta mogu se postići pomoću oznake br kada ne želimo započeti novi odlomak.
